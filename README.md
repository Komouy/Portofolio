# Kadal API — Web Developer & AI Enthusiast (React Port)

Website portofolio interaktif bergaya retro modern & pixel art milik Moch Dhaifan Al Qhadafy (KadalApi), dibangun ulang sebagai aplikasi React + TypeScript + Vite.

## Fitur Utama

- **Pixel Art Visuals & Mascot**: Animasi pixel fox interaktif dengan eye-tracking, salto somersault, klik counter, dan balon dialog interaktif.
- **Fox Runner: Pixel Dash**: Game arcade retro 2D mandiri lengkap dengan synthesizer audio Web Audio API chiptune 8-bit, rintangan dinamis, skor terbaik tersimpan lokal, dan efek CRT scanlines.
- **Pengelola Proyek & GitHub Importer**:
  - Panel pengelola proyek dengan keamanan verifikasi PIN admin (terenkripsi SHA-256).
  - Sinkronisasi repositori GitHub langsung dari `@Komouy`.
  - Penambahan & pengeditan proyek kustom dengan kompresi gambar lokal otomatis dan tag manager.
- **PortoBot AI (Gemini Assistant)**:
  - Asisten AI interaktif dengan pengetahuan lengkap seputar layanan, daftar harga, dan keahlian teknis.
  - Formulir konsultasi cerdas terintegrasi langsung ke WhatsApp dan Email.
- **Tema & Bahasa**:
  - Mode terang / gelap dengan transisi mulus.
  - Dwibahasa penuh (Bahasa Indonesia & Bahasa Inggris).
- **Efek Retro Interaktif**:
  - Kanvas partikel dan cursor glow.
  - Kartu dengan tilt 3D dinamis dan interaksi sentuh.
  - Tombol magnetik dan loop marquee kontinu dengan fisika swipe/drag.

## Menjalankan Proyek

```bash
# Instal dependensi
npm install

# Mode Pengembangan (Port 3000)
npm run dev

# Membangun untuk Produksi
npm run build

# Menjalankan Server Produksi
npm start
```
